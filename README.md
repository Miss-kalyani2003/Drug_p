# 💊 Drug Prediction System using Machine Learning

## 📌 Project Overview

The **Drug Prediction System** is a machine learning–based application that predicts the most suitable drug for a patient based on medical conditions such as age, gender, blood pressure, cholesterol level, and disease type.
This project helps demonstrate how ML models can support **clinical decision-making** by analyzing patient data.

---

## 🎯 Problem Statement

Choosing the right drug for a patient depends on multiple factors. Manual decision-making can be time-consuming and error-prone.
This system automates drug prediction using historical medical data and machine learning algorithms.

---

## 🚀 Features

* Predicts appropriate drug based on patient details
* Supports multiple classification algorithms
* Simple and user-friendly input interface
* High accuracy with proper preprocessing
* Can be extended to real-world healthcare applications
